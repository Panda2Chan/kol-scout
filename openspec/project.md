# 项目约束

## 语言

- OpenSpec 目录下所有面向人阅读的文档必须使用简体中文。
- OpenSpec schema 必需的结构关键字可以保留英文，例如 `ADDED Requirements`、`Requirement`、`Scenario`、`WHEN`、`THEN`。
- 新增 proposal、design、spec、tasks、归档说明和实施记录时，正文、任务描述、决策说明和验收说明都必须使用简体中文。

## 产品背景

KOL Scout 是面向大陆出海团队的 Chrome 插件，用于发现、筛选、保存和导出海外 KOL 线索。产品默认语言是中文，工程文档也应服务于中文协作。
